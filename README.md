# ShoScout 虾小探

ShoScout 虾小探是一款免费的 Shopee 竞品监控助手。本仓库提供公开产品介绍、使用帮助、隐私政策和服务条款。

- 产品首页 https://shoscout-dev.github.io/shoscout-docs/
- 帮助中心 https://shoscout-dev.github.io/shoscout-docs/help.html
- 隐私政策 https://shoscout-dev.github.io/shoscout-docs/privacy.html
- 服务条款 https://shoscout-dev.github.io/shoscout-docs/terms.html

## 部署

静态 HTML 网站。GitHub Pages 使用 main 分支根目录，资源采用相对路径，保留 `.nojekyll`。

## 内容与素材

仓库仅包含公开网页、样式、导航脚本、品牌图、首页概念插图和帮助页功能演示截图。截图使用合成示例数据或经处理的公开演示素材。品牌图由开发者提供，首页概念插图使用图像生成工具制作。网站不包含扩展源代码或用户业务数据库。

产品当前免费，在浏览器本地运行。采集与下载需要网络。Chrome 商店审核期间，可从产品首页下载 `assets/downloads/ShoScout-1.1.0-store.zip`；商店审核通过后再更新为官方安装入口。
